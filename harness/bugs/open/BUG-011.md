# BUG-011 — An unreadable save leaves RESUME MISSION permanently active

| Field | Value |
| --- | --- |
| Bug ID | `BUG-011` |
| Title | An unreadable save leaves RESUME MISSION permanently active |
| Severity | Low |
| Priority | P3 |
| Feature | FEAT-003, FEAT-009 |
| Environment | browser (jsdom reproduces it) |
| Status | OPEN |

**Preconditions:** `localStorage.snake_mission_save` contains data that `deobfuscate()` cannot read.

## Steps to Reproduce

1. Seed a corrupt save
2. Mount the hub and observe `hasSavedGame` / the RESUME MISSION button
3. Click RESUME

## Expected

The corrupt save is discarded: the button disappears or resuming explains the problem.

## Actual

`hasSavedGame` stays true forever; `handleResume()` returns early without clearing the item, so the button is a permanent no-op.

## Reproducible

YES (TC-042b).

## Evidence

`test-results/latest/ui.tap` (TC-042b)

## Root Cause

`useSnakeGame.handleResume` bails out on a `null` deobfuscation without removing the storage key.

## Fix

On `null`, remove the key and reset `hasSavedGame`.
