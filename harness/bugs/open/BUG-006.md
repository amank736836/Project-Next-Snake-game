# BUG-006 — `generateFood` recurses without a bound when the board is full

| Field | Value |
| --- | --- |
| Bug ID | `BUG-006` |
| Title | `generateFood` recurses without a bound when the board is full |
| Severity | Low |
| Priority | P3 |
| Feature | FEAT-001 |
| Environment | unit level (pure function) |
| Status | OPEN |

**Preconditions:** A board in which all 400 cells are occupied.

## Steps to Reproduce

1. Call `generateFood(fullBoard)` in a unit test

## Expected

Terminate with a defined outcome (no free cell / error value).

## Actual

`RangeError: maximum call stack size exceeded`.

## Reproducible

YES (TC-010) — unreachable in normal play.

## Evidence

`test-results/latest/unit.tap` (TC-010)

## Root Cause

`utils.ts → generateFood` recurses until it finds a free cell; there is no exit condition for a full board.

## Fix

Collect the free cells and pick one, or bound the attempts and return `null`.
