# BUG-007 — Obfuscation throws for names containing characters above U+00FF

| Field | Value |
| --- | --- |
| Bug ID | `BUG-007` |
| Title | Obfuscation throws for names containing characters above U+00FF |
| Severity | Low |
| Priority | P3 |
| Feature | FEAT-009 |
| Environment | unit level (pure function) |
| Status | OPEN |

**Preconditions:** A mission whose player name contains non-Latin1 characters (e.g. `Игрок`).

## Steps to Reproduce

1. Call `obfuscate(mission)` in a unit test

## Expected

The mission is encoded and can be decoded again.

## Actual

`DOMException: Invalid character` — `btoa` is Latin-1 only.

## Reproducible

YES (TC-011) — reachable only through the API or imported data, since the UI strips non-ASCII input.

## Evidence

`test-results/latest/unit.tap` (TC-011)

## Root Cause

`utils.ts → obfuscate` uses `btoa` directly.

## Fix

Encode through `TextEncoder`/`encodeURIComponent` before base64, and decode symmetrically.
