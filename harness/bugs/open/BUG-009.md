# BUG-009 — The foul-word list contains duplicate entries

| Field | Value |
| --- | --- |
| Bug ID | `BUG-009` |
| Title | The foul-word list contains duplicate entries |
| Severity | Low |
| Priority | P3 |
| Feature | FEAT-007 |
| Environment | unit level (data hygiene) |
| Status | OPEN |

**Preconditions:** `src/lib/foulWords.ts` imported.

## Steps to Reproduce

1. Find entries whose first index differs from their last index

## Expected

No duplicates.

## Actual

Duplicates exist (for example `tranny`, `kinky`), inflating the list scanned on every submission.

## Reproducible

YES (TC-029).

## Evidence

`test-results/latest/unit.tap` (TC-029)

## Root Cause

Entries added over time without a dedupe step.

## Fix

Deduplicate at import (`[...new Set(RAW.map(w => w.toLowerCase()))]`) — fixes BUG-008 and BUG-009 together.
