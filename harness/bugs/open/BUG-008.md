# BUG-008 — The foul-word list contains non-lower-case entries that can never match

| Field | Value |
| --- | --- |

| Title | The foul-word list contains non-lower-case entries that can never match |

| Environment | unit level (data hygiene) |

**Preconditions:** `src/lib/foulWords.ts` imported.

## Steps to Reproduce

1. Filter the list for `word !== word.toLowerCase()`

## Expected

Every entry is lower-case (the route compares against a lower-cased name).

## Actual

Entries with upper-case characters exist; they are dead weight that can never fire.

## Reproducible

YES (TC-028).

## Evidence

`test-results/latest/unit.tap` (TC-028)

## Root Cause

Manual list maintenance without normalisation.

## Fix

Normalise once at import: `export const foulWords = RAW.map(w => w.toLowerCase())`.
